# اسکرپ محصولات و ارسال گزارش اکسل با ایمیل

یک ابزار خط فرمان با پایتون: آدرس صفحه‌ی لیست محصولات یک فروشگاه و ایمیل گیرنده را می‌گیرد، محصولات را صفحه‌به‌صفحه اسکرپ می‌کند، یک فایل اکسل می‌سازد و آن را به ایمیل گیرنده می‌فرستد.

> **توجه:** این پروژه فقط برای تمرین و یادگیری است. پیش از اسکرپ هر سایت، `robots.txt` و شرایط استفاده‌ی آن را بررسی کنید و درخواست‌ها را آرام و کم‌حجم بفرستید. فقط برای کسانی ایمیل بفرستید که گزارش را می‌خواهند.

## امکانات

- ورودی از ترمینال: آدرس سایت، ایمیل گیرنده و تعداد صفحه
- تنظیمات هر سایت (selectorها) در فایل `sites.py`؛ افزودن سایت جدید بدون تغییر منطق برنامه
- صفحه‌بندی خودکار و توقف در صفحه‌ی خالی یا خطا
- تلاش مجدد (`retry`) هنگام قطعی یا کندی سایت
- تشخیص قیمت تخفیف‌خورده
- ارسال ایمیل با پیوست اکسل از طریق Gmail

## تنظیم ایمیل

1. در حساب گوگل، **تأیید دو مرحله‌ای** را روشن کنید.
2. از بخش **App passwords** یک رمز ۱۶ حرفی بسازید.
3. فایل `.env.example` را کپی کنید و اسمش را `.env` بگذارید، سپس مقدارها را پر کنید:

```
EMAIL_ADDRESS=your_email@gmail.com
EMAIL_PASSWORD=your_16_char_app_password
```

رمز را بدون فاصله و بدون گیومه بنویسید. فایل `.env` هرگز نباید روی گیت برود.


## افزودن سایت جدید

در `sites.py` یک بلوک با دامنه‌ی سایت اضافه کنید. selectorها را با کلیک راست ← `Inspect` پیدا کنید:

```python
"example.ir": {
    "item": "li.product",                      # ظرف هر محصول
    "name": "h2.product-title a",              # اسم و لینک
    "price": ["span.price ins bdi", "span.price bdi"],
    "link_attr": "href",
    "page_url": "{base}page/{page}/",          # الگوی صفحه‌های بعدی
},
```

## محدودیت‌ها

- سایت‌هایی که محتوا را با جاوااسکریپت می‌سازند با `requests` کار نمی‌کنند.
- ارسال با Gmail ممکن است از برخی شبکه‌ها بدون ابزار دسترسی مناسب باز نشود.
