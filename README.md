# اسکرپ محصولات، مقایسه‌ی قیمت و ارسال خودکار گزارش

یک ابزار خط فرمان با پایتون: آدرس صفحه‌ی لیست محصولات یک فروشگاه و ایمیل گیرنده را می‌گیرد، محصولات را صفحه‌به‌صفحه اسکرپ می‌کند، قیمت‌ها را با گزارش قبلی مقایسه می‌کند، یک فایل اکسل فرمت‌شده می‌سازد و آن را با ایمیل و تلگرام می‌فرستد. با Task Scheduler ویندوز می‌تواند هر روز خودکار اجرا شود.

> **توجه:** این پروژه فقط برای تمرین و یادگیری است. پیش از اسکرپ هر سایت، `robots.txt` و شرایط استفاده‌ی آن را بررسی کنید و درخواست‌ها را آرام و کم‌حجم بفرستید. فقط برای کسانی ایمیل بفرستید که گزارش را می‌خواهند.

## امکانات

- ورودی از ترمینال: آدرس سایت، ایمیل گیرنده و تعداد صفحه
- تنظیمات هر سایت (selectorها) در `sites.py`؛ افزودن سایت جدید بدون تغییر منطق برنامه
- صفحه‌بندی خودکار، توقف در صفحه‌ی خالی یا خطا و تلاش مجدد (`retry`)
- تشخیص قیمت تخفیف‌خورده
- **گزارش تاریخ‌دار:** هر اجرا یک فایل `reports/report_YYYY-MM-DD.xlsx` می‌سازد
- **مقایسه‌ی قیمت با گزارش قبلی:** شیت `Changes` با وضعیت `Up`، `Down`، `New` و `Removed`، مقدار تغییر و درصد تغییر
- **فرمت‌بندی اکسل:** هدر رنگی، ردیف ثابت، جداکننده‌ی هزارگان و رنگ‌بندی ردیف‌های تغییر (قرمز گرانی، سبز ارزانی، آبی جدید، خاکستری حذف‌شده)
- ارسال گزارش با **ایمیل** (Gmail) و **تلگرام** (بات)
- اجرای زمان‌بندی‌شده با Task Scheduler

## تنظیمات

فایل `.env.example` را کپی کنید، اسمش را `.env` بگذارید و مقدارها را پر کنید. این فایل هرگز نباید روی گیت برود.

```
EMAIL_ADDRESS=your_email@gmail.com
EMAIL_PASSWORD=your_16_char_app_password
TELEGRAM_TOKEN=your_bot_token
TELEGRAM_CHAT_ID=your_chat_id
```

### ایمیل (Gmail)

1. در حساب گوگل، **تأیید دو مرحله‌ای** را روشن کنید.
2. از بخش **App passwords** یک رمز ۱۶ حرفی بسازید.
3. رمز را بدون فاصله و بدون گیومه در `.env` بنویسید.

### تلگرام

1. در تلگرام با `@BotFather` یک بات بسازید (`/newbot`) و توکن را بگیرید.
2. به بات خودتان یک پیام بفرستید.
3. با آدرس `https://api.telegram.org/bot<TOKEN>/getUpdates` مقدار `chat_id` را پیدا کنید.
4. توکن و `chat_id` را در `.env` بنویسید.

## نحوه اجرا

```
python main.py "آدرس_صفحه_محصولات" ایمیل_گیرنده
python main.py "آدرس_صفحه_محصولات" ایمیل_گیرنده --pages 3
```

اجرای اول فقط گزارش را می‌سازد. از اجرای دوم (در روزی دیگر) شیت `Changes` هم اضافه می‌شود.

## اجرای خودکار (Task Scheduler ویندوز)

1. `run.example.bat` را کپی کنید و اسمش را `run.bat` بگذارید، سپس مسیر پروژه، آدرس و ایمیل را عوض کنید.
2. در Task Scheduler با **Create Basic Task** یک وظیفه‌ی روزانه بسازید و `run.bat` را به عنوان برنامه بدهید.
3. خروجی و خطاها در `log.txt` ذخیره می‌شوند.

## افزودن سایت جدید

در `sites.py` یک بلوک با دامنه‌ی سایت اضافه کنید. selectorها را با کلیک راست ← `Inspect` پیدا کنید:

```python
"example.ir": {
    "item": "li.product",                      # ظرف هر محصول
    "name": "h2.product-title a",              # اسم و لینک
    "price": ["span.price ins bdi", "span.price bdi"],
    "link_attr": "href",
    "page_url": "{base}page/{page}/",          # الگوی صفحه‌های بعدی
},
```

## محدودیت‌ها

- سایت‌هایی که محتوا را با جاوااسکریپت می‌سازند با `requests` کار نمی‌کنند.
- Gmail و تلگرام ممکن است از برخی شبکه‌ها بدون ابزار دسترسی مناسب باز نشوند. برای اجرای خودکار، آن ابزار باید همان لحظه هم روشن باشد.
- مقایسه‌ی قیمت بر اساس لینک محصول انجام می‌شود؛ اگر سایت آدرس محصول را عوض کند، به عنوان `New` و `Removed` دیده می‌شود.

## نکته

اگر هنگام اجرا خطای `PermissionError` دیدید، فایل گزارش را در اکسل ببندید و دوباره اجرا کنید.
